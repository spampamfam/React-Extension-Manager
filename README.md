## 📖 Overview

**React Extension Manager** is a responsive React application for managing extensions: activate/deactivate, filter, and remove them easily.

## ✨ Features

- Toggle active/inactive state
- Remove extensions dynamically
- Filter by All / Active / Inactive
- Responsive grid layout
- Smooth animations with Framer Motion
- Persistent state in Local Storage

## 🛠️ Built With

- React
- Vite
- Tailwind CSS
- Framer Motion
- ESLint
- JSON (data source)

## 📱 Responsive Design

- 1 column on mobile
- 2 columns on tablets
- 3 columns on desktop

## 🎬 Animations

- Cards fade & slide in on load
- Cards slide out smoothly on removal
- Layout transitions automatically adjust on filtering
